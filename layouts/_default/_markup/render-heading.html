{{/* render-heading.html — Markdown heading render hook Intercepts Markdown headings (h1-h6) and appends a clickable anchor link (🔗) that appears on hover. This lets users right-click the anchor to copy a direct URL to that section. Hugo calls this hook for every Markdown heading, providing: .Level — the heading level (1-6) .Anchor — the auto-generated id attribute .Text — the heading text content .Page — the current page object The whole tag is built as a single pre-escaped string via printf + safeHTML rather than a normal href="#{{ .Anchor }}" attribute. Building the tag as one already-escaped blob sidesteps that per-attribute escaping entirely, keeping href and id byte-identical. This hook only applies to Markdown content.
