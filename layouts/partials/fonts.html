{{/* fonts.html — Self-hosts Google Fonts at build time. Why: loading fonts from fonts.googleapis.com puts a three-hop chain on the critical render path — document, then the stylesheet, then the woff2 from fonts.gstatic.com — across two cold connections. The stylesheets are only a few KB, so the cost is connection setup and chain depth, not bytes. Fetching everything at build time and republishing it locally collapses that to a single same-origin request on the already-warm connection, and removes both Google origins from the page. See toph#79. Accepts a slice of dicts, one per configured family: - "family": Name from site.Params.fonts.* (may be empty — empty entries are skipped, because `family=` returns HTTP 400 and would cost a render-blocking round trip to fetch an error) - "cdn": Weight fragment from partials/font-weight.html (":wght@500") Emits an inline {{- end -}} {{- end -}}
