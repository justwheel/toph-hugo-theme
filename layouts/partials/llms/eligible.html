{{- /* llms/eligible.html — is this page's source file published? Context: dict "page" PAGE "cfg" CONFIG "lang" STRING Returns: bool Eligibility is about the source export only; it says nothing about a page's suitability for the /llms.txt index, which is curated separately. Deliberate exclusions: - No backing file, or a format other than Markdown/AsciiDoc. - A page the public build is withholding, which `llms/published.html` decides for the index selectors as well. - A page in a language the sources config does not select. `hide_sitemap` and `taxonomy_exclude` are NOT consulted. They describe listing and sitemap behavior; reusing them here would silently drop the Projects section, which is public content with a real HTML page. */ -}} {{- $page := .page -}} {{- $cfg := .cfg -}} {{- $lang := .lang -}} {{- $ok := false -}} {{- with $page.File -}} {{- if and (in (slice "md" "adoc") .Ext) (eq $page.Lang $lang) (partial "llms/published.html" $page) -}} {{- $src := $cfg.sources -}} {{- /* Exact membership against the validated list. `all` is a separate flag, so no arbitrary string ever reaches this test and `es` cannot match `es-mx`. */ -}} {{- $lang_ok := or $src.all (in $src.langs $page.Lang) -}} {{- if $lang_ok -}} {{- $bare := strings.Trim $page.Path "/" -}} {{- if not (or (in $src.exclude_pages $bare) (in $src.exclude_sections $page.Section)) -}} {{- $ok = true -}} {{- end -}} {{- end -}} {{- end -}} {{- end -}} {{- return $ok -}}
